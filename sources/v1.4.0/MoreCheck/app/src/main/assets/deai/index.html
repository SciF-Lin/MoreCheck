API 接入说明（供 App / 第三方集成）
本页面基于 WorkBuddy 云服务的大模型通道（免密钥），并提供一个浏览器端 JS 接口，可直接被其他页面或 App 内嵌 WebView 调用：
  • 全局接口：window.DeAIAPI.rewrite(text, options)，返回 { rewritten, report }
  • options：{ strength: '轻度'|'中度'|'重度', style: '通用'|'学术论文'|'公众号'|'口语化', model?: string }
  • 查询可用模型：window.DeAIAPI.listModels()
const { rewritten, report } = await window.DeAIAPI.rewrite(
  '值得注意的是，随着技术的不断进步，这一变化意义重大。',
  { strength: '中度', style: '口语化' }
);
// rewritten -> 降 AI 率改写后的文本
// report    -> 修改说明要点
后端通道为当前应用云服务的 /.cloud/llm/chat/completions（OpenAI 兼容、仅流式），由云服务按应用 Origin 鉴权，密钥不落地前端。其他 App 集成时，建议同样引入 @tencent-ai/workbuddy-cloud-sdk 并使用各自的云服务环境，而不是直接代理本页接口。
