# MoreCheck

MoreCheck 是一款**本地优先的个人打卡与效率工具**。日常打卡、统计和提醒都在设备本机完成，不登录也能正常使用；登录后可把打卡数据同步到云端，换设备也能接着用。

## 主要功能

- **每日打卡**：为待养成的习惯或待办事项建立任务，轻点圆形按钮完成打卡；支持一次勾选多个任务批量打卡，并带动画、震动与撒花反馈。
- **日历视图**：按月查看每一天的打卡状态，区分已打卡、未打卡与缺卡；可对最近 7 天内的缺卡记录补打卡，也能撤销误操作。
- **统计与记录**：用热力图直观看到每日完成度，时间线按日期倒序回看打卡历史，精确到分钟。
- **每日提醒**：每个任务都可以设置提醒时间，到点推送本地通知；开机后自动重排，不需要常驻后台轮询。
- **外观设置**：支持浅色、深色、跟随系统，并可切换主题色（不同版本的选项略有差异）。
- **账号与云同步**：手机号注册，支持**验证码登录**与**密码登录**两种方式；登录后任务、打卡记录、记事本、应用设置与游戏存档会在后台自动同步（`1.1.90` 提供完整同步，`1.1.70` 目前仅提供账号登录）。
- **实验室工具**（较新版本）：计时器、记事本、课程表、扫一扫、网页搜索与若干小游戏，按需取用。
- **隐私优先**：不登录时打卡数据只留在本机；不植入广告或统计组件；云同步、智能体、网页浏览等联网功能都由你主动开启才会触发。

> 不同版本的功能范围略有差异，`1.1.90` 为功能最完整的版本，请以应用内实际界面为准。

## 安装方法

**手机上安装**

1. 下载上表中对应版本的 APK 到手机。
2. 在系统设置中允许安装来自未知来源的应用：通常在「设置 → 安全」或「设置 → 隐私 → 特殊权限 → 安装未知应用」中，给浏览器或文件管理器开启权限。
3. 用文件管理器打开 APK，按提示完成安装。
4. 首次启动时，按引导阅读并同意用户协议与隐私政策（较新版本），并允许通知权限以启用打卡提醒。

**电脑上安装（可选）**

连接手机并开启 USB 调试后执行：

```bash
adb install -r MoreCheck-1.1.70.apk
```

## 校验安装包

下载完成后建议核对 SHA-256：

```powershell
Get-FileHash .\MoreCheck-1.1.70.apk -Algorithm SHA256
```

```bash
sha256sum MoreCheck-1.1.70.apk
```

输出哈希应与上表一致。

## 常见问题

- **提示「解析包错误」**：通常是下载不完整，请重新下载并核对哈希。
- **无法安装**：确认已允许「安装未知来源」，并检查手机剩余存储空间。
- **收不到打卡提醒**：检查通知权限、Android 12+ 的精确闹钟权限，以及系统电池优化是否限制了本应用。
- **检查更新跳到哪里**：会打开系统浏览器，进入本仓库的 Releases 页面。
- **忘记密码怎么办**：目前没有接入短信找回，可改用「验证码登录」进入账号。
- **登录后没看到旧数据**：首次登录会让你选择合并方式（上传本机 / 下载覆盖 / 暂不处理），选错了可在「云同步」页手动同步一次。
- **找不到历史打卡数据**：数据仅保存在本机，卸载应用会一并清除；卸载前请先使用应用内的数据备份功能。
