## 2. 逐版本明细

### 2.1 MoreCheck 1.1.90（当前推荐）

**上游基线**：CheckInMate `v1.1.90`（2026-10-23，`versionCode 39`，上游 1.1 系列的收尾正式版）。

**上游这一版的内容**（用户日志原文）：

- 日历当天记录去掉「收起」按钮与补打卡提示文字
- 修复了若干细节问题，优化应用体验

上游这一版还带着 1.1.80 ~ 1.1.82 引入的能力：真实手机验证码登录、云同步与同步管理页、首次登录合并策略、课程表三视图、游戏存档、记事本、智能体、数据备份到云端，以及热搜与今日待办（后两者在 MoreCheck 里已删除）。

**MoreCheck 侧改动**（这才是本包与上游的真正差异）：

| 类别 | 改动 |

| 功能裁剪 | 删除**天气**、**热搜**、**今日待办**三个实验室功能；连带删除 `assets/todo`、`LabRealPage`/`LAB_ITEMS` 入口、`TabDestination`/路由、`AppContainer.weatherRepository`、`HOT_SEARCH_API_URL` 设置项 |

## 5. 版本号规则

1. **跟上游走**，不自造 1.0.x：上游发了 `v1.2.0`，MoreCheck 就叫 `1.2.0`，`versionCode` 用上游的值。
2. `versionCode` **只增不减**；同版本修 bug 重出时保持版本号不变，替换 `dist/` 文件与 Release 同名资产。
3. 上游 beta 不进 MoreCheck 发布线（本项目只发正式版），需要灰度时另开分支。
4. 每次发版必须在 `README.md`、本文件、应用内 `ChangelogScreen.RELEASES` 三处留痕，缺一处就会出现"用户看到的更新日志和实际不一致"。
